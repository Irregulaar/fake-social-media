# fake-social-media

Recreación de las pantallas de chat de **X (Twitter)** y **Facebook Messenger**, hecha con React, Tailwind y Vite. El objetivo era practicar UI: fuentes, iconos, spacing y esos detalles que hacen que un clon se sienta real.

> **Demo:** temporalmente fuera de línea. Para verlo, corre el proyecto localmente.

## Rutas

- `/` o `/twitter` — chat de X, con la fuente Chirp y la estética oscura.
- `/facebook` — chat de Messenger, con la fuente Roboto y la estética clásica.

## Stack

React 19 · Tailwind CSS 4 · Vite · React Router

## Correr localmente

```bash
pnpm install
pnpm dev
```

## Nota

Es un ejercicio de interfaz, no una app real de mensajería: no hay backend ni mensajes de verdad.
